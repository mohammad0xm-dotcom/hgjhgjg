المرحلة 0: القياس فقط

هذه نسخة اختبار منفصلة تماماً عن V3 (أيقونة برتقالية باسم CardScan P0). V3 لا يُلمس ولا يُستبدل. سلوك القراءة هو نفسه حرفياً، وأُضيف فقط قياس الأزمنة وعدد المحاولات وأسباب الرفض.

1) نشرها في مستودع جديد (لا تلمس cardscan)

  1. على اللابتوب: في GitHub اضغط + ثم New repository، الاسم cardscan-p0، Public، ثم Create.
  2. فك ضغط CardScan60K-Phase0.zip ثم Add file ثم Upload files واسحب الملفات (ما عدا هذا الدليل إن شئت) ثم Commit changes.
  3. Settings ثم Pages ثم Branch: main و / (root) ثم Save. الرابط: https://ahmadjawabrah11-collab.github.io/cardscan-p0/

2) على كل جوال (7 جوالات)

  1. افتح الرابط في Safari والإنترنت شغال، ثم Add to Home Screen، وافتح التطبيق من الأيقونة البرتقالية.
  2. اكتب موديل الجوال (مثل 13 Pro Max) واختر الوضع handheld أو stand.
  3. اضغط Device speed test (حوالي دقيقة، لا تحتاج مغلفاً). ثم Export report واحفظ الملف.

3) بروتوكول الاختبار (حوالي 100 مغلف حقيقي)

  1. 50 مغلفاً باليد (handheld)، ثم 50 مغلفاً على حامل ثابت (stand): الجوال مثبّت، مسافة ثابتة، والمغلف يُوضع على حاجز كرتون يجعل نافذته في مكان واحد، وإضاءة جانبية ناعمة بدون لمعان على النافذة.
  2. اضغط START SCANNING وامسح المغلفات كالعادة بدون لمس الشاشة. لا تغيّر أي شيء في طريقتك.
  3. بعد كل 25 مغلفاً تقريباً: Verify results. اضغط كل سجل وقارنه بالورق: Matches the paper ✓ أو Does not match ✗ مع كتابة القيم الصحيحة. سجلات REVIEW اكتب لها القيم الصحيحة. هذه الخطوة أهم خطوة لقياس الدقة.
  4. اضغط Benchmark stats لترى الملخص، ثم Export report.

4) ماذا ترسل لي

ملف p0-report-….json فقط. لا يحتوي أرقام حسابات ولا أرقام بطاقات ولا أسماء ولا صوراً: فقط أزمنة وعدادات وأسباب رفض وعلامات صح/خطأ. لا ترسل ملفات Excel أو النسخ الاحتياطية أو لقطات شاشة فيها أرقام.

5) تنبيهات

  • بيانات P0 منفصلة عن V3، لكن الموقع (github.io) واحد: لا تمسح بيانات Safari للموقع، فهذا يمسح V3 أيضاً.
  • سجلات P0 للاختبار فقط: لا تدمجها مع بيانات V3 الحقيقية ولا تصدّرها للعمل.
  • إذا أُغلق التطبيق فجأة أثناء المسح سيُسجَّل ذلك تلقائياً كحدث، وهو معلومة مفيدة عن الذاكرة.
